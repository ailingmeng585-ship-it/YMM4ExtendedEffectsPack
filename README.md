# YMM4 Extended Effects Pack

YMM4向けの **17種の映像エフェクト・8種の場面切り替え・56種類の映像用プリセット**を単一DLLにまとめたC#／HLSLプラグインです。依頼された14種に、調査で選んだ3種を追加しています。

> **0.1.0 / 実機未検証のα版。** 実SDK参照でのC#ビルドとDXCによるHLSL構文チェックは成功していますが、WindowsでのSM5コンパイル・Direct2D描画・YMM4のUI／保存復元／書き出しは未検証です。完成・動作保証済みのリリースではありません。バックアップを取ったテスト用プロジェクトでお試しください。

## 対応環境・計画書との相違

- Windows 10/11 x64、.NET 10版YMM4（v4.47以降の系統）。実際に使用するYMM4のDLLを参照してビルドします。
- Direct3D 11 / Shader Model 5対応GPU。SM4、Feature Level 9.x、CPUフォールバックは非対応。
- [公式の開発案内](https://manjubox.net/ymm4/faq/plugin/how_to_make/)に合わせ、計画書の.NET 8を **.NET 10** に変更しました。
- 配布形式は公式の **`.ymme`**。計画書の `.ymme4` ではありません。
- 場面切り替えは現行の `ITransitionPlugin` / `TransitionParameterBase` / `ITransitionSource` を実装。真偽値UIは `ToggleSlider` です。
- HLSLはDLLに埋め込み、Windows標準の `d3dcompiler_47.dll` で初回だけ `ps_5_0` にコンパイルします。外部素材は不要です。

### 追加3種の調査根拠

- インクにじみ：[CapCut Ink Transition Effect](https://www.capcut.com/explore/ink-transition-effect)。テンプレート素材の流用ではなく、HLSLノイズから形状を生成しました。
- ルミナンス・メルト：[Adobe After Effects / Gradient Wipe](https://helpx.adobe.com/after-effects/desktop/apply-effects-and-animation-presets/list-of-effects/transition-effects.html)。輝度に基づく透明化を参考に、元映像の輝度と液状変形を組み合わせました。
- プリズム・ウィップ：[CapCut Whip Pan](https://www.capcut.com/resource/ai-camera-transitions-whip-pan-match-cut)、[Pan Transition](https://www.capcut.com/explore/pan-transition)。パンに色収差・ブラーを組み合わせた独自実装です。

調査日：2026-09-10。魚眼・万華鏡・輪郭発光・残像・ゴッドレイ等は[公式コミュニティ実装](https://github.com/manju-summoner/YukkuriMovieMaker.Plugin.Community)にも関連機能があるため、「YMM4に存在しない」とは宣伝しません。追加3種についても、すべての外部プラグインとの非重複や流行度ランキングを保証するものではありません。CapCut／Adobeのソース・有償素材は流用していません。

## 導入・使い方

1. YMM4を更新し、テスト用プロジェクトを用意します。
2. `.ymme` を開いてプラグインをインストールし、YMM4を再起動します。
3. 手動導入する場合は、終了したYMM4の `user/plugin/YMM4.ExtendedEffectsPack/` に **`YMM4.ExtendedEffectsPack.dll` だけ**配置します。フォルダ名は `plugins` ではなく `plugin` です。
4. 「設定 → プラグイン」で読み込み状態を確認し、映像エフェクト一覧で `EEP` を検索します。場面切り替え一覧にも8種を登録する設計です。

ダウンロードしたDLLがWindowsにブロックされた場合はファイルのプロパティで解除を確認します。本体SDKのDLLをプラグインフォルダにコピー・上書きしないでください。削除する場合はYMM4を終了して当該フォルダだけを取り除きます。

- **カーテン／まばたき**：映像版は0で閉、100で開。まばたきの「目覚め」初期値は閉です。キーフレームで開き具合を上げてください。
- **場面切り替え版**：前後2映像を受け取り、アイテム長に応じて自動進行。カーテン・まばたきは一度閉じて次の映像を開きます。
- **アイテム登場／退場**：映像版の進行度をキーフレーム指定します。独立した自動登場・退場エフェクトの登録はありません。
- **インク／ルミナンス映像版**：0で透明、100で表示。下のレイヤーと組み合わせられます。
- **フィルムバーン／プリズム映像版**：進行度を0→100へ動かしてください。静止した0のままでは効果が出ません。
- **ブロック／マトリックス映像版**：進行度は表示量。波・コードの動作はアイテム内時刻で進みます。
- **シェイク**：アイテム先頭を衝撃の開始として減衰します。途中で衝撃を出す場合はアイテムを分割します。自動音ハメではありません。
- **プリセット**：選択変更時に設定・キーフレームを初期化します。同じ選択肢を再選択しても再適用されません。
- **点滅への注意**：虹色・雷・鼓動・フラッシュには光過敏性発作等のリスクがあります。低速・低強度から調整し、視聴者にも配慮してください。

## ビルド・検証

.NET 10 SDKとYMM4本体を用意し、リポジトリのルートから実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\build.ps1 -Ymm4Dir "C:\Tools\YukkuriMovieMaker4"
```

C#ビルド → 埋め込みHLSLのSM5コンパイル → WindowsのWARPソフトウェアGPUでDirect2Dテスト → `.ymme` 作成の順に実行します。テストが失敗した場合はパッケージを生成しません。WARPテストの成功とYMM4編集画面での検証は別です。

```powershell
# ビルドだけ行う場合
dotnet build .\src\YMM4.ExtendedEffectsPack -c Release --warnaserror -p:Ymm4Dir="C:\Tools\YukkuriMovieMaker4"
# 構造テスト（Python標準ライブラリのみ）
python -m unittest discover -s tests -p "test_*.py" -v
```

`build.ps1` に `-SkipWindowsTests` を付けるとWindows検証を省略できますが、出力名は `.alpha-unverified.ymme` になります。成果物は `artifacts/` に出力します。

## 制約・未対応

- **色のキーフレーム補間は未対応**。数値は `Animation`、色は固定 `ColorPicker`、モードは離散値です。計画書の全項目との完全一致ではありません。
- カーテンはシェーダーによる布風の陰影・圧縮であり、物理布シミュレーションではありません。ブロックも2D変形・陰影です。
- 発光は基本的に入力画像の範囲内。独立したHDRブルームや範囲外へ大きく張り出す発光は未実装です。
- マトリックスは独自4×7ドット字形。カタカナは数種類の簡易字形で、完全な日本語フォントではありません。
- ゴッドレイは24サンプルの放射ぼかし＋角度パターン。物理的なボリューム散乱ではありません。
- RGB残像は1つの過去フレームを分離・合成します。最初の数フレームは残像なし。逆シーク・フレーム飛び・画面サイズ／遅延値変更・入力クリアで履歴を破棄するため、先頭から連続再生してください。
- 履歴画像は**インスタンスごと128 MiBを目安に制限**し、超過時は残像だけ低解像度化します。GPU管理領域・現在画像・一時描画領域は別途必要です。
- 残像はアイテムの位置・回転・拡縮をシーン座標に焼き込みます。特殊なビルボードや複雑なグループ・後段3D効果との組み合わせは未検証です。
- BPM位相は最大256点の数値積分で、短い急変・ランダム変化には近似誤差があります。
- スリットスキャン、オプティカルフロー、自動音ハメ、真のスピードランプ連動は含めません。
- 無限サイズの生成エフェクトは先にクロップしてください。上限16384px/辺は許容寸法で、性能保証ではありません。
- AviUtl/EXOへのエフェクト変換は非対応です。

## 開発者向け構成

`src/YMM4.ExtendedEffectsPack/` 内の `Common/` がGPU・履歴管理、`Effects/` が17モデル、`Transitions/` が8種の登録と2入力描画、`Shaders/Pack.hlsl` が共通シェーダーです。

設定定義を変更するときは `tools/generate_effects.py` を編集し `python tools/generate_effects.py` を実行します。生成済みC#も管理しているため、通常のビルドにPythonは不要です。HLSLのA/B/Cの順序は、カタログの色以外のパラメータ順と一致させてください。

公式参考：[プラグインの作り方](https://manjubox.net/ymm4/faq/plugin/how_to_make/) ／ [公式サンプル](https://github.com/manju-summoner/YukkuriMovieMaker4PluginSamples)。
