# YMM4 Extended Effects Pack

ゆっくりMovieMaker4 向けの統合映像エフェクト／トランジションパックです。

ヒアリング仕様の **14 種**に加え、CapCut / TikTok / Premiere / After Effects で 2025–2026 に需要が高く、YMM4 標準にはないモダン演出を **20 種**追加しています（合計 **34**）。各エフェクトは Direct2D カスタムピクセルシェーダー（HLSL `ps_5_0`）で、パラメータは日本語 UI・キーフレーム対応です。

進行度を持つものは映像エフェクトのままトランジションとしても使えます（0→100% をキーフレーム）。

## ビルド（Windows）

前提: YMM4 v4.47 以降（.NET 10）、Visual Studio 2022 または .NET SDK、Windows SDK の `fxc.exe`。

1. このリポジトリをクローン
2. `Directory.Build.props` の `YMM4DirPath` を `YukkuriMovieMaker4.exe` のあるフォルダに合わせる（末尾 `\` 必須）
3. `fxc.exe` を PATH に入れる
4. `dotnet build -c Release YMM4.ExtendedEffectsPack/YMM4.ExtendedEffectsPack.csproj`
5. 成功すると `user/plugin/YMM4.ExtendedEffectsPack/` に DLL がコピーされる
6. YMM4 を再起動し、映像エフェクトの「拡張エフェクト」を開く

GPU がシェーダーを読めない場合は無処理でフォールスルーします。

## プロジェクト構成

```
Directory.Build.props
YMM4.ExtendedEffectsPack/
  Common/          共通プロセッサ・定数バッファ
  Effects/         [VideoEffect] クラス（日本語パラメータ）と CustomEffect
  Shaders/         HLSL ps_5_0（fxc で .cso を埋め込み）
```

- パラメータは各エフェクト 10 個以内
- 主要な数値は `Animation`（キーフレーム対応）
- ドロップダウンは `EnumComboBox`、色は `ColorPicker`
- エフェクトごとに固有の Direct2D CustomEffect 型（シェーダー登録の衝突を避ける）
